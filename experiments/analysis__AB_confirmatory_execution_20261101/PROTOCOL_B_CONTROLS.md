## Root clarification: fixed implementable baseline cells

FIT32 name-pair blocks, main so/when only, both recipient sides. Obtain z and native branch output once per literal (128 full captures). Fit direction from equal weights over templates,blocks and sides: mean female z minus mean male z,normalized. This is the same fixed FIT population used for baseline labels; not an independent evaluation or population replication. Zero/nonfinite direction fails, no alternative direction search.

For each FIT recipient and each of2operators×6doses, define undosed delta_z=(donor z-z) or its projection onto frozen w, and ACTUAL edit h=c*delta_z. Native D=N(z+h)-N(z). Share native endpoints with all baselines and diagnostics; do not acquire separate labels per method. New perturbed local native branch evaluations:128*12=1536, plus one local N0 per recipient unless already available as a scheduled JVP primal. Local N0 is not silently identified with capturedM0; qualification checks their agreement. No full downstream forward is required merely to fit these vector baselines.

Mean baseline:24 template/operator/dose cells ×2recipient sides, each averaging32 native vectors. Ridge:24 cells,64 rows each (32blocks×2sides); global scalar RMS of the ACTUAL h inputs in that cell (dose applied exactly once), centered inputs/outputs, unpenalized intercept,n*lambda penalty,lambda=.01, no SELECT/hyperparameter search. Lambda is fixed before FIT. Preserve signs and recipient-side convention; no observed-readout selection of cell,operator or dose.

Transfer baseline uses a separately fitted pooled main-template model:for each operator/dose,128rows(two equally weighted templates,32blocks,two sides),same fixed ridge recipe. Pooled mean is the arithmetic mean of the two template-specific means for the same side/operator/dose. The pooled ridge is fitted on pooled rows; it is NOT the average of two coefficient matrices. Transfer uses these frozen pooled objects with no transfer-native labels for fitting. These extra fits are CPU algebra, not extra native calls.

Apply every predicted vector as native recipient M0+D_pred and propagate through the identical native remainder. Since layer15 is not the last layer, the last-layer final-norm shortcut used in A is invalid. Until an exact truncated suffix adapter is independently verified, use one full native forward with only the layer15 final-position output replaced. A local branch evaluation/JVP is counted separately from that full downstream forward. Zero prediction reuses baseline margin exactly, requiring no new forward. Shared endpoint/capture results are not remeasured for controls or secondary analyses.

## Endpoint and linear diagnostics: exact aggregation

For each fixed template/operator/dose, retain all block/side records,compute scalar energies within record then average sides equally and blocks equally. e0/e1 are float64 differences of actually stored float32 endpoint outputs; log FP32-vs-FP64 subtraction discrepancy separately. With total weight1,mu0=sum(w*e0),mu1=sum(w*e1),centered cross C=sum(w*dot(e1-mu1,e0-mu0)),so mean dot(e1,e0)=dot(mu1,mu0)+C. Use population-weight denominator,not n-1,for this exact energy identity. Then mean||e1-e0||²=mean||e1||²+mean||e0||²-2mean dot(e1,e0). Report signed cross term without clipping or treating shares as causal percentages.

Obtain g=gradient of native finite-suffix readout with respect to layer15 output at unedited recipient M0 once per measured recipient,not per dose/method. Reuse g for g·D_TC vs g·D_native and g·D_TC vs actual finite margin change; these are different targets. One backward and its necessary forward per recipient must be scheduled and counted. This descriptive diagnostic is not needed to fit mean/ridge; if operationally separated, it must bind the identical endpoints/recipients and never repeat existing forwards solely for bookkeeping.

All secondary contrasts remain descriptive with paired-block uncertainty,99% construction labeled as such,without support labels or promotion into B1–B3. Primary family and its calibration remain separate. Controls/negative outcomes retained; all acquired data included even when the selected positive regime does not replicate.

Primary symbols E and S always mean squared FINITE MARGIN error and squared native FINITE MARGIN change, in logit². Secondary vector norms/energies use explicit vector prefixes and never feed primary B1–B3 by substitution. Base endpoints N0/N1 are local native branch outputs; intervention anchor remains capturedM0. Native finite readout is the full native model with layer15 output replaced by M0+(N1-N0), minus captured unedited margin. Equality to the input-edit path is qualified on fixed recipients before expansion.
